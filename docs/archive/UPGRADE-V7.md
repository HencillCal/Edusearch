# EduSearch AI V7 — Rights Compliance and Takedown Workflow

V7 adds a production-oriented rights and copyright layer without removing the existing search, OCR, moderation, personalization or private-library functionality.

## Lawful upload declaration

Every non-draft upload must include:

- A legal sharing basis: own work, rights-holder permission, public domain, or institution-authorized publication
- Optional source or attribution details
- An explicit good-faith confirmation that the uploader may distribute the document

The same requirement applies to documents generated by the OCR reconstruction workflow. A platform administrator cannot make the declaration for another contributor.

## Copyright request workflow

A rights holder can submit a request without creating an account. The request records:

- Referenced document
- Claimant identity and relationship to the work
- Requested action
- Detailed statement
- Optional private PDF, DOCX or image evidence
- A random tracking code whose hash, rather than plaintext, is stored in the database

Evidence is kept outside public document storage and is accessible only to administrators.

## Administrator actions

Administrators can:

- Mark a claim as under review
- Temporarily restrict a document
- Contact the uploader
- Restore a document
- Keep it restricted
- Remove confirmed infringing material
- Dismiss unsupported claims

Restriction removes the document from public and private-library search, previews, downloads, recommendations, saves and related-document results. Administrators retain inspection access for case review.

## OCR rights enforcement

V7 adds these fields to OCR jobs:

- `rights_basis`
- `source_attribution`
- `rights_declared`
- `rights_declared_by`
- `rights_declared_at`

The contributor may save a declaration with the OCR job. An administrator can publish a contributor-owned OCR job only after that declaration exists. Anonymous OCR jobs can be claimed by the authenticated user who provides the declaration and publishes them.

## Migration

Existing V6 databases migrate automatically. New rights fields receive conservative defaults and existing OCR/document content, revisions, search indexes, users, libraries and moderation records remain intact.
